dokumen root adalah lokasi folder dimana file website dari sebuah situs disimpan,atau direktori (folder) yang disimpan di server host Anda dan ditujukan untuk menyimpan halaman web
Pada XAMPP, dokumen root atau home directory berada di folder htdocs, yaitu C:\xampp\htdocs, karena Folder htdocs terinstall secara otomatis saat Anda menginstal XAMPP, Semua data website PHP atau HTML (kecuali database) harus ditempatkan di dalam folder htdocs, Untuk mengorganisir project website, Anda bisa membuat folder untuk masing-masing project website.
GIT= Membuat repositori Git baru  dalam sebuah folder proyek di direktori saat ini, git init= untuk membuat repositori Git baru dalam sebuah folder proyek, git clone= untuk menyalin repositori yang sudah ada dari server atau penyimpanan lain ke komputer lokal, git remote= untuk mengelola URL repositori jarak jauh (remote repository), git add= untuk menambahkan perubahan file ke staging area, sehingga siap untuk dikomit, git commit= untuk menyimpan perubahan secara permanen ke dalam riwayat Git, git push= untuk mengirim (mengunggah) perubahan yang sudah dikomit dari repositori lokal ke repositori remote, git checkout=  untuk berpindah ke cabang lain atau untuk mengembalikan file ke keadaan sebelumnya.
GitHub= Layanan hosting berbasis Git yang terkenal dan banyak digunakan oleh komunitas open-source serta perusahaan untuk kolaborasi kode, sedangkan GitLab= Layanan hosting Git yang lebih berorientasi pada DevOps, menyediakan fitur lengkap dari manajemen kode hingga CI/CD (Continuous Integration/Continuous Deployment). GitHub lebih populer dan banyak digunakan untuk kolaborasi open-source, sedangkan GitLab menawarkan kontrol lebih besar dan fitur CI/CD yang lebih baik, terutama untuk perusahaan yang ingin menjalankan sistemnya sendiri.
Variable User= Variabel yang hanya berlaku untuk pengguna tertentu di komputer tersebut, Disimpan dalam pengaturan pengguna di dalam registry (Windows) atau dalam file konfigurasi pengguna (~/.bashrc, ~/.profile di Linux), dapat diubah oleh Hanya pengguna yang bersangkutan, Jika ada variabel dengan nama yang sama di sistem, variabel user memiliki prioritas lebih tinggi dalam sesi pengguna tersebut. Jika ada variabel dengan nama yang sama di sistem, variabel user memiliki prioritas lebih tinggi dalam sesi pengguna tersebut. Sedangkan Variable System= Variabel yang berlaku untuk semua pengguna dalam sistem, Disimpan dalam registry Windows atau dalam file sistem global seperti /etc/environment atau /etc/profile di Linux, Hanya administrator (Windows) atau user dengan hak akses root (Linux), Variabel sistem menjadi default jika tidak ada variabel user dengan nama yang sama.
persamaannya Menyimpan Nilai yang Digunakan Secara Global karena Keduanya menyimpan nilai yang dapat digunakan di seluruh sistem atau program, Digunakan untuk Konfigurasi atau Pengaturan karena ariable system digunakan dalam sistem operasi, sementara constant dalam pemrograman digunakan untuk nilai tetap yang tidak boleh berubah, Dapat Mempengaruhi Program atau Sistem karena Keduanya bisa berdampak pada jalannya sistem atau program. Misalnya, perubahan pada JAVA_HOME (variable system) bisa memengaruhi aplikasi berbasis Java, sedangkan perubahan pada constant bisa memengaruhi logika program.
